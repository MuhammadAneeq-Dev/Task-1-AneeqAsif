# Creative Studio

A modern and responsive **Creative Studio website** built using HTML5 and CSS3.

## Features

* Clean and modern design
* Responsive layout
* Home, About, Services & Contact sections
* Hover effects
* Mobile-friendly design

## Technologies

* HTML5
* CSS3
* Google Fonts (Poppins)

## How to Run

Simply open `index.html` in your web browser.
